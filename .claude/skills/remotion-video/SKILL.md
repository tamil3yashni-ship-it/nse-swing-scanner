# Remotion Video Skill

When user types /remotion-video:

1. Create a Remotion composition
2. Register it in Root.tsx
3. Add animations using:
   - spring()
   - interpolate()
   - Sequence
   - AbsoluteFill
4. Open preview:
   npx remotion studio
5. Render video:
   npx remotion render

Default:
- 1080x1920
- 30fps
- Modern animations
- Clean typography
